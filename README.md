One funny, true line reviewing the most boring everyday object imaginable —
the doorstop: kicked every day, thanked never, and still holding the door
open like it runs the place. The joke comes from how the object really
behaves, not a gag that would fit anything.

## Run

```
node main.ts
```

Writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
The entry is a single line, 1–200 characters, with no trailing newline.
